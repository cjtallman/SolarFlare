# SolarFlare

This repository is intended to preserve the original project files for **SolarFlare** - a DigiPen student project I worked on in 2009.

The code has bugs and unfinished features, and honestly, some silly decisions representing our lack of experience as students. But it's also interesting to see some of the challenges we needed to solve.

## Archive status

The recovered material includes C++ source, game assets, and a Visual Studio 2005 solution. The archive is intended to preserve the project rather than provide a working build.

To avoid licensing issues with third-party dependencies (some which have no original provenance), libraries and headers are omitted. Each dependency has a README documenting what was originally present. Any modifications that were made to the third-party headers is preserved as a diff.

## Git LFS

Git LFS is configured for binary assets and other retained binary files.

```sh
git lfs install
git clone https://github.com/cjtallman/SolarFlare.git
```
