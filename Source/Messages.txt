Format:
  "TypeName"
  Stack1
  Stack2
  ...
  StackN

Creating Messages From Lua:
GameLib.AddMessage( destination,    - "global" or "entity"
                    "TypeName",     - Any string
                    TimeDelay,      - Any number
                    Route,          - MSG_ALL, MSG_LOCAL, MSG_ALL_PEERS, MSG_SINGLE_PEER - destination(s) of message
                    stack[0],       - First item on message stack
                    ...,            - ...
                    stack[n]        - Last item on message stack
                   )
